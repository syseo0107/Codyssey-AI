# 프롬프트 템플릿

> 주제 하나를 받아 인스타그램·블로그·X 텍스트와 대표 이미지 프롬프트를 만드는 프롬프트 4개의 설계와 수정 기록.
> 기록 순서: **초안(v0) → 수정(v1, v2 …) → 최종**. 초안은 고치기 전 상태 그대로 둔다.

---

## 1. 공통 설계 원칙

| 원칙 | 이유 |
| --- | --- |
| 역할은 한 줄, 바로 과업 | 군더더기 지시가 많을수록 형식 조건을 놓친다 |
| 바뀌는 값은 자리 표시 `[주제]` `[대상]` `[톤]` | n8n에서 폼 값 `{{ $json.topic }}` `{{ $json.audience }}` `{{ $json.tone }}`으로 바꿔 넣는다 |
| 조건은 셀 수 있는 숫자로 | Code 노드([tools/check.js](tools/check.js))로 자동 검증하려면 숫자 기준이 필요하다 |
| 하지 말 것을 따로 적기 | 인사·자기소개, 확인할 수 없는 통계가 반복해서 나오기 때문 |
| 출력은 JSON만 | 다음 노드가 필드를 나눠 노션 열에 넣는다 |

### 수치 기준과 근거

| 플랫폼 | 미션 기준 | 프롬프트 목표값 | 근거 |
| --- | --- | --- | --- |
| 인스타그램 | 짧은 캡션 + 해시태그 10개 내외 | 본문 3~5줄, 해시태그 정확히 10개 | "내외"는 검증할 수 없어 10으로 고정 |
| 블로그 | 500자 이상 + 소제목 구조 | 공백 포함 800~1,200자, 소제목(##) 3개 | 모델이 글자 수를 적게 세는 경우를 대비해 여유를 둠 |
| X | 280자 이내 | 해시태그 포함 120자 이내 | 실제 X는 한글 1자를 2로 세서 한국어 상한이 약 140자. 실제 게시 기준까지 맞춤 |

**v1에서 새로 생긴 문제 → v2 방향**

| 문제 | 원인 추정 | v2 방향 |
| --- | --- | --- |
| GPT-4o 캡션이 1줄 | 출력 예시를 `"캡션"` 한 단어로 줄임 | 예시를 `"첫 줄\n본문\n마지막 줄"`처럼 구조가 보이게 |
| Haiku JSON 깨짐 (2/4) | 큰따옴표·줄바꿈을 이스케이프하지 않음 | 프롬프트에 "줄바꿈은 \\n, 따옴표는 작은따옴표"를 명시한다. API의 JSON 출력 모드도 켜려 했으나, 실제로 쓴 Codyssey 서버가 지원하지 않아 검사 후 재생성으로 대신했다 (v3 재시험 참고). 처음 계획한 문구: n8n에서는 API의 JSON 출력 모드를 켜고, 프롬프트에도 "줄바꿈은 \\n, 따옴표는 작은따옴표" 명시 |
| GPT-4o 블로그 길이 초과 (v0·v1 연속) | 글자 수를 적게 셈 | 목표를 900~1,100자로 좁히거나 모델에서 제외 |
| Haiku 지어낸 수치 ("2시간", "60%") | 단정 금지만으로는 부족 | "숫자는 주제에 나온 것(예: 10분)만" 으로 범위를 좁힘 |

**모델 선택:** Gemini 3.8 Flash가 v0·v1 8번 모두 기준을 지켰다. 워크플로우의 텍스트 생성 모델로 Gemini를 1순위로 둔다.

## v3 재시험: 워크플로우용 API (2026-11-28)

- **왜 다시 했나:** 발급받은 키는 OpenAI 직접 키가 아니라 **Codyssey 중계 서버**(`https://copa.codyssey.kr/v1`, OpenAI 호환) 키였다. 이 서버에서 고를 수 있는 모델로 최종 프롬프트를 다시 확인해야 했다.
- **바꾼 것:** 프롬프트는 v3 최종 그대로. 요청에서 JSON 모드(`response_format`)를 뺐다. 서버가 `400 unsupported_feature`로 거절했기 때문이다.
- **조건:** 주제 1·주제 2 × 4개 프롬프트, 모델 2개 (`tools/text-check.js`로 API 직접 호출)
- **원본 결과:** [시험기록/v3-codyssey/](시험기록/v3-codyssey)

| 프롬프트 | gpt-5.4-mini 주제 1 | gpt-5.4-mini 주제 2 | gpt-5.5 주제 1 | gpt-5.5 주제 2 |
| --- | --- | --- | --- | --- |
| 인스타그램 | 통과 (태그 10, 5줄) | 통과 (태그 10, 5줄) | 통과 (태그 10, 5줄) | 통과 (태그 10, 5줄) |

| 이미지 | 통과 | 통과 | 통과 | 통과 |

- **gpt-5.4-mini 8/8, gpt-5.5 7/8.** JSON 모드 없이도 16개 응답 모두 올바른 JSON이었다. v3의 따옴표 규칙이 제 역할을 했다.
- **gpt-5.5는 실제로는 gpt-5-mini가 답했다.** 응답의 `model` 값이 `gpt-5-mini`였다. 서버가 큰 모델 요청을 작은 모델로 바꿔 처리하는 것으로 보인다. gpt-5.4-mini는 요청한 모델이 그대로 답했다.
- **최종 모델: `gpt-5.4-mini`.** 통과율이 가장 높고, 요청한 모델이 그대로 답한다.
- **남은 약점:** 블로그가 하한 800자 근처(807자, 793자)로 나오는 일이 있다.
  - 워크플로우는 기준을 벗어나면 최대 3번 다시 생성하도록 했다.
  - 그래도 자주 걸리면 프롬프트의 목표값을 900~1,100자에서 950자 이상으로 올리는 v4를 검토한다.
- **이미지 생성:** 이 서버에서 `/v1/images/generations`는 404였다. 그래서 대표 이미지는 **Gemini API `gemini-3.1-flash-image`**(1:1)로 만든다. 이미지 프롬프트(영어, 글자 없음)는 그대로 썼다. 결과는 1024×1024, 글자가 들어가지 않은 이미지였다.
- **n8n 실행:** 실행 #11(주제 1)에서 4개 모두 첫 시도에 통과했고, 노션 4행이 저장됐다.
  - 블로그 807자, X 94자, 이미지 프롬프트 631자로 위 주제 1 시험과 글자 수가 같았다.
  - 서버가 같은 요청에 응답을 재사용(캐시)했을 가능성이 있지만, 확인하지 않았다.

## 2. 인스타그램

**설계 의도:** "더 보기" 전에 보이는 첫 줄이 승부처. 첫 줄 훅 → 짧은 본문 → 저장·댓글 유도 → 해시태그 10개.

### v0 (초안)

```text
너는 인스타그램 캡션 작가야
주제는 [주제], 보는 사람은 [대상], 톤은 [톤]이야
- 첫 줄: "더 보기"를 누르기 전에 읽히는 한 문장. 인사·자기소개 없이 결과나 궁금증으로 시작
- 본문: 3~5줄, 한 줄에 한 가지 내용
- 마지막 줄: 저장이나 댓글을 부르는 한 문장
- 해시태그: 정확히 10개, 넓은 태그와 좁은 태그를 섞어서
- 확인할 수 없는 통계·수치는 쓰지 마
출력은 JSON만: {"caption": "...", "hashtags": ["#...", ...], "hook_type": "첫 줄에 쓴 훅 기법"}
```

### v1

```text
너는 인스타그램 캡션 작가야
주제는 [주제], 보는 사람은 [대상], 톤은 [톤]이야
- 첫 줄: "더 보기"를 누르기 전에 읽히는 한 문장. 인사·자기소개 없이 결과나 궁금증으로 시작
- 본문: 3~5줄, 한 줄에 한 가지 내용
```

## 5. 대표 이미지 프롬프트

**설계 의도:** LLM이 이미지 생성 AI용 영어 프롬프트를 먼저 쓰고, 그 프롬프트로 이미지를 만든다. 글자·로고·실존 브랜드를 빼서 저작권 문제를 피한다.

### v0 (초안)

```text
너는 SNS 대표 이미지 아트디렉터야
주제 [주제]로 이미지 생성 AI에 넣을 영어 프롬프트 1개를 써줘
- 장면 하나, 주인공 하나
- 스타일, 색감, 구도를 각각 한 줄로
- 이미지 안에 글자, 로고, 실존 브랜드, 캐릭터를 넣지 않기
- 정사각형(1:1)
출력은 JSON만: {"image_prompt": "..."}
```

### v1

```text
너는 SNS 대표 이미지 아트디렉터야
주제 [주제]로 이미지 생성 AI에 넣을 영어 프롬프트 1개를 써줘
- 장면 하나, 주인공 하나
- Style:, Color:, Composition: 세 줄로 나눠서 각각 한 줄씩
- 이미지 안에 글자, 로고, 실존 브랜드, 캐릭터를 넣지 않기
- 프롬프트 끝에 반드시 "square 1:1, no text, no logos"를 넣어
출력은 JSON만: {"image_prompt": "..."}
```

### v2

```text
너는 SNS 대표 이미지 아트디렉터야
주제 [주제]로 이미지 생성 AI에 넣을 영어 프롬프트 1개를 써줘
- 장면 하나, 주인공 하나
- 장면 묘사 뒤에 Style:, Color:, Composition: 세 부분을 이어서 써. 부분 사이는 \n으로 구분
- 이미지 안에 글자, 로고, 실존 브랜드, 캐릭터를 넣지 않기
- 프롬프트 끝에 반드시 square 1:1, no text, no logos를 넣어
- JSON 문자열 안의 줄바꿈은 \n으로 쓰고, 큰따옴표 대신 작은따옴표를 써
출력은 JSON만: {"image_prompt": "장면 묘사\nStyle: ...\nColor: ...\nComposition: ..., square 1:1, no text, no logos"}
```
