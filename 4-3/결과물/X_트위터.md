# X (트위터) 게시글

- **주제:** 겨울철 집에서 하는 10분 운동
- **만든 곳:** n8n 워크플로우 "AI 소셜 콘텐츠 자동 생성". Codyssey `gpt-5.4-mini`로 생성하고 노션에 저장한 결과를 그대로 옮겼다.
- **기준:** 해시태그 포함 120자 이내, X 가중치 길이 280 이하(한글 1자 = 2), 해시태그 2개 이하, 인사 없이 결론이나 긴장감으로 시작
  - 미션 기준은 280자다. 하지만 실제 X는 한글을 2로 세기 때문에 한국어 상한이 약 140자다. 실제로 올릴 수 있는 길이에 맞추려고 120자를 기준으로 잡았다 (프롬프트템플릿.md "수치 기준과 근거").

## A/B 비교

| 항목 | A (친근) | B (전문) |
| --- | --- | --- |
| 말투 | "~요" 체 | "~습니다 / ~세요" 체 |
| 구성 | 구체적인 처방 (세트·분·초) + 생활 팁 | 동작마다 효과 한 줄씩 |
| 길이 | 94자 | 84자 |

- 두 버전 모두 첫 문장을 결론("10분만 움직여도 ~")으로 시작했다. 훅 유형은 톤과 상관없이 같았다.
- A의 "3세트, 2분, 30초"는 운동 처방이다. 효과를 부풀린 통계가 아니라서 "지어낸 수치 금지" 규칙에 걸리지 않는다.
