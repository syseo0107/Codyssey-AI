# 미해결 기록

산출물 4 · 프롬프트를 수정해도 원하는 결과를 얻지 못한 과업 기록

> 상태: 실제 실험 전 / 미해결 사례 미확정
>
> 아래 두 항목은 기록 양식이며 실제 실패 사례가 아니다.
> 실제 실행 후 끝내 해결하지 못한 과업으로 채운다.
> 해결된 사례는 최종 미해결 목록에서 제외한다.

## 1. 작성 원칙

- 실제 시도한 과업만 기록한다.
- 첫 응답에서 문제가 있었더라도 수정 후 해결됐다면 미해결로 세지 않는다.
- 시도한 프롬프트와 받은 응답은 원문을 보관한다.
- 막힌 이유는 작성자가 직접 쓴다.
- 원인을 확정할 수 없으면 관찰한 현상과 멈춘 지점을 구분해 적는다.
- 입력 누락을 되묻거나 모른다고 답한 정상 행동을 실패로 세지 않는다.
- 실험 전 후보와 실제 미해결 사례를 구분한다.

## 2. 실험 후보 — 아직 미해결 사례 아님

다음은 확인해볼 수 있는 상황이다.
실제로 발생하지 않았다면 미해결 사례로 옮기지 않는다.

| 후보 상황 | 확인할 문제 | 정상적인 대응 |
|---|---|---|
| 흐린 영수증 이미지 | 메뉴·금액을 반복해서 잘못 읽는가 | 판독 불가 부분을 밝히고 선명한 자료 요청 |
| 긴 대화 후 새 가게 입력 | 변경한 문장 수를 계속 잊는가 | 최신 조건을 유지하고 가게별 정보를 분리 |
| 긍정·부정 경험 혼합 | 부정적 경험을 반복해서 누락하는가 | 경험의 의미와 강도를 유지 |
| 제한된 분량에 경험 다수 입력 | 핵심 경험이 계속 누락되거나 왜곡되는가 | 조건 충돌 시 우선순위를 확인 |
