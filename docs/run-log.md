| 20 | AI | Step 블록 | |

### 19턴에 쓸 브리프

```text
[브리프]
세션: 2. 플래닝 기반 슈퍼바이저로 자동 조사 보고서 파이프라인 만들기
Step: 3. Canvas 에이전트 연결 + 통합 파이프라인 실행
시연 목적: 조사 결과로 보고서를 쓰고 저장하는 canvas를 붙이고, 주제 한 줄로 보고서가 나오는 것을 확인
만들 파일: session2/canvas_agent.py, session2/make_graph.py, langgraph.json
조건: 저장 도구 1개(save_to_file), 목차+본문 한 번에 작성(max_tokens=2000), 소절마다 출처 링크, recursion_limit=20
완료 기준: Studio에서 주제 입력 → outputs/*.md 생성 + planning이 최종 답변 후 종료
비용: gpt-4o 약 12~15회 + Tavily 1~2회, 약 $0.15~0.25

위 브리프로 시연 Step 블록 하나를 작성해줘.
```

> 확인할 것: 5턴에서 바꾼 "관찰 포인트 2개", "비용 칸은 호출 횟수만"이 20턴에도 유지되는가. 유지되지 않으면 `🔗 [문맥 끊김]` 표시.
