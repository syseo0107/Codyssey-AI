## 제출 전 체크리스트

문서
- [ ] `[서비스 정체성]` 블록이 문서 맨 앞에 있고 이름, 한 줄 소개, 톤앤매너가 있음
- [ ] 대상 고객, 차별점(USP), 캠페인 목표(인지), 핵심 메시지 한 문장
- [ ] 스토리 구조(기승전결) 표기
- [ ] 모든 씬이 `[씬 N]`으로 시작하고 10개 필드가 채워짐
- [ ] 씬마다 사용 도구와 고른 이유가 직접 적혀 있음
- [ ] 카테고리(`[이미지 생성]`, `[영상 생성]`, `[오디오 생성]`)를 표시한 프롬프트 3건 이상
- [ ] 문서의 프롬프트가 실제로 입력한 글과 같음
- [ ] 수정 전후 프롬프트, 수정 후 결과, 바꾼 이유 1건 이상
- [ ] 텍스트·이미지·영상·오디오 도구 각 1종 이상, 약관의 상업적 이용 확인 결과
- [ ] 파일명 규칙 설명
- [ ] 최종 영상 파일명, 길이, 해상도 (내보낸 파일에서 확인한 값)
- [ ] 작업 기록이 한 줄에 작업 하나이고 무엇을 어떻게 했는지 드러남
- [ ] `✏️`가 남아 있지 않음
- [ ] `스토리보드_머물지도.pdf`로 변환함

영상
- [ ] MP4 한 건, 5초 이상 10초 이내
- [ ] 짧은 변 720픽셀 이상
- [ ] AI로 생성한 시각 요소와 청각 요소가 모두 있음
- [ ] 마지막 3초에 브랜드명, 슬로건, 행동 유도 문구가 보임
- [ ] 워터마크 여부를 확인하고 도구 목록에 적음
- [ ] 파일 이름이 `광고_머물지도.mp4`

제약
- [ ] 실존 인물, 실존 상표(참고한 서비스 이름과 로고 포함)를 생성하지 않음
- [ ] 직접 촬영한 소재, 유료 스톡을 쓰지 않음
- [ ] 편집 도구로 새 소재를 생성하지 않음
