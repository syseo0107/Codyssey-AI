## 스테이폴리오를 어떻게 반영했나 (먼저 읽기)

미션에는 "실존 상표를 생성 대상으로 쓰지 않는다"와 "광고 대상은 통합 미션에서 만들 서비스로 고정한다"는 제약이 있다. 그래서 스테이폴리오 자체를 광고하지 않고, **그 방향을 참고한 자체 서비스**를 광고한다.

| 스테이폴리오에서 참고한 것 | 머물지도에서 바꾼 것 |
| --- | --- |
| 머무는 곳 자체가 여행의 목적이 된다는 관점 | 그대로 가져와 핵심 메시지로 삼음 |
| 관점을 갖고 고른 스테이만 소개하는 큐레이션 | 수백 곳을 보여 주는 대신 질문 하나에 한 곳만 추천 |
| 매거진 같은 차분한 글과 사진 | 말투와 사진 톤의 방향만 참고. 색은 오프화이트·먹색·쑥색으로 따로 정함 |
| 지역과 날짜로 찾는 검색 | 쉬는 방식(창밖 보기, 책 읽기 등)을 먼저 묻는 방식 |

프롬프트와 영상 어디에도 "스테이폴리오"라는 이름, 로고, 화면 캡처, 실제 숙소 이름을 넣지 않는다. 생성 도구에 스테이폴리오 사진을 레퍼런스로 넣는 것도 피한다.

## 1단계. 도구 확정과 한도·약관 확인 (약 30분)

### 고른 도구

| 분류 | 도구 | 고른 이유 (스토리보드 "사용 목적"에 직접 다시 적는다) |
| --- | --- | --- |
| 텍스트 | Claude (초안), 리브레챗 4모델 (문안 비교·확정) | 초안은 이미 Claude로 작성함. 1-1에서 쓰던 리브레챗으로 같은 요청을 4모델에 보내 비교하면 "같은 요구를 여러 도구로 시도한 비교"가 텍스트에서도 생긴다 |
| 이미지 | Dreamina 이미지 생성 (Seedream) | 영상과 같은 곳에서 만들면 이미지를 바로 첫 프레임으로 넘길 수 있고, 색과 질감이 영상 단계에서 덜 바뀐다 |
| 영상 | Dreamina 영상 생성 (Seedance) | 이미지를 첫 프레임으로 넣는 기능이 있고, 무료 일일 크레딧으로 짧은 클립을 만들 수 있다 |
| 음성 | 한국어 TTS 1종 (Typecast, 클로바더빙, ElevenLabs 가운데 열리는 것) | Seedance도 소리를 만들 수 있지만 한국어 내레이션 문장을 정확히 읽히는 용도로는 TTS가 맞다 |
| 음악 | 음악 생성 1종 (Suno 등) | 10초 피아노 연주곡 |
| 편집 | CapCut (웹 또는 데스크톱) | Dreamina와 같은 회사 도구라 소재를 옮기기 쉽다. 한글 자막 서체가 있다 |

> **편집 도구의 AI 기능은 쓰지 않는다.** CapCut에도 TTS, 자동 자막 음성, AI 배경 같은 생성 기능이 있지만 미션은 편집 도구를 자르기·자막·색보정·오디오 조정·크기 조정까지만 허용한다. 내레이션은 CapCut TTS가 아니라 별도 음성 도구로 만든다.

### Dreamina에서 먼저 확인할 것 (스토리보드 6장에 적는다)

아래 값은 2026-11 기준 공개 글에서 본 것이다. **한국 계정 값은 다를 수 있으니 로그인한 화면에서 직접 확인한 값만 문서에 적는다.**

| 항목 | 공개 글에서 본 값 | 직접 확인할 곳 |
| --- | --- | --- |
| 무료 일일 크레딧 | 미국 계정 하루 120 크레딧, 지역마다 다름 | 화면 오른쪽 위 크레딧 표시 |
| Seedance 영상 크레딧 | 공식 고정가 없음. 모델·길이·해상도·모드에 따라 생성 버튼에 표시. 제3자 추정으로 Seedance 2.0 초당 약 17, 2.0 Mini 초당 약 5 | 생성 버튼 옆 크레딧 숫자 |
| 고를 수 있는 모델 | Seedance 2.0, 2.0 Mini, 2.5(최신) 등 요금제·지역에 따라 다름 | 모델 선택 목록 |
| 워터마크 | 무료 결과물에 워터마크가 붙는다는 안내가 많음 | 내려받은 파일 |
| 상업적 이용 | 공식 FAQ는 "약관과 모델에 따라 다름"이라고만 적음. 무료는 비상업 개인 이용이라는 리뷰가 있음 | 약관(Terms of Service)에서 해당 문장 찾기 |

- 워터마크는 지우거나 잘라 내지 않는다. 붙어 있으면 그대로 두고 "무료 요금제 워터마크 있음"이라고 도구 목록에 적는다. 미션은 워터마크를 금지하지 않고, 확인했다는 기록을 요구한다.
- 상업적 이용은 "가능 / 유료 요금제만 가능 / 불가 / 약관에서 명확히 찾지 못함" 가운데 하나로 적고 약관 문장을 짧게 인용한다.

### 크레딧 계획 (가성비)

영상이 크레딧을 가장 많이 쓴다. 계획은 이렇다.

1. **해상도는 720p**로 생성한다. 미션 기준(짧은 변 720)을 넘기고 크레딧은 1080p보다 덜 든다. 최종 영상도 1280x720으로 맞춘다.
2. **길이는 고를 수 있는 가장 짧은 값**으로 생성한다. 편집에서 2~3초만 잘라 쓴다.
3. **먼저 저렴한 모델(Mini 또는 Draft 모드)로 씬 4개를 모두 한 번 만든다.** 움직임이 의도대로 나오는지 확인하는 용도다.
4. 크레딧이 남거나 다음 날 크레딧이 들어오면 **가장 중요한 씬 3(필요하면 씬 2)만 상위 모델로 다시 만든다.** 이 차이를 5장 수정 기록이나 보너스 2의 비교 재료로 쓴다.
5. 생성할 때 **소리 생성 옵션이 있으면 끈다.** 크레딧이 더 들 수 있고, 내레이션·배경음악과 겹친다. 켜서 만들었다면 편집에서 음소거한다.
6. 생성 전마다 버튼 옆 크레딧 숫자를 [작업기록.md](작업기록.md)에 함께 적어 둔다. 6장의 "무료 한도" 칸을 채울 근거가 된다.

## 2단계. 리브레챗으로 문안 비교 (약 30분)

1. 리브레챗에서 새 대화를 열고 웹 검색을 끈다. 1-1과 같은 조건이다.
2. [prompts/librechat-copy.txt](prompts/librechat-copy.txt)를 그대로 붙여 넣고 Solar Pro 4, GPT 4o, Gemini 3.8 flash, Claude Haiku 4.5에 각각 보낸다. 모델마다 새 대화를 연다.
3. 답을 복사해 `assets/01_text/s00_txt_copy_<모델>_v1.md`로 저장한다. 예: `s00_txt_copy_solar_v1.md`.
4. 스토리보드 6-1장 표에 모델마다 다섯 가지 기준(음절 수, 느낌표·가격 문구 없음, 권유형 어미, 이름 포함, 씬 화면과 맞는지)을 O/X로 적는다.
5. 지금 초안(Claude)과 4모델 답 가운데 하나를 고르거나 섞어 확정한다. 고친 줄이 있으면 4장 내레이션과 씬 4 자막도 함께 고친다. 바꾸지 않았다면 "비교 결과 초안을 유지함, 이유:"를 적는다.

## 3단계. 이미지 4장 생성 (Dreamina, 약 40분)

1. Dreamina 이미지 생성에서 비율을 **16:9**로 고른다. 생성 전에 스토리보드 3-1장 샷리스트를 한 번 본다.
2. 프롬프트는 [prompts/dreamina-image.txt](prompts/dreamina-image.txt)에 한국어 원문과 영어 번역이 함께 있다. **한국어를 먼저 넣어 보고**, 결과가 프롬프트를 잘 따르지 않으면 영어 번역으로 다시 만든다. 이 차이도 수정 기록 재료가 된다. 실제로 넣은 글을 스토리보드에 옮긴다.
3. 씬 3을 먼저 만든다. 광고의 인상을 정하는 장면이라 이것이 마음에 들어야 나머지 색을 여기에 맞출 수 있다.
4. 씬 2, 씬 4는 씬 3 결과를 참고 이미지로 넣어 색을 맞춘다.
5. 한 번에 여러 장이 나오면 고른 한 장만 규칙대로 저장한다(`assets/02_image/s03_img_room_v1.png`). 다시 만들면 `v2`로 올리고 `v1`은 지우지 않는다.
6. 샷리스트와 맞춰 본다. 피사체가 정한 3분할 위치에 있는지, 자막 자리(S2 아래 20%, S4 위 3분의 2)가 비었는지, S2와 S3에서 책·찻잔이 모두 오른쪽 3분의 1에 있는지. 다르면 다시 생성하고 수정 기록 재료로 남긴다.
7. 씬마다 "출력 결과 요약"을 바로 적는다.

## 4단계. 영상 4개 만들기 (Dreamina Seedance, 약 1시간, 대기 시간 포함)

1. Dreamina 영상 생성에서 **이미지로 영상 만들기(첫 프레임)** 를 고르고 3단계 이미지를 넣는다.
2. 모델은 1단계 크레딧 계획대로 고른다. 해상도 720p, 길이는 가장 짧은 값, 소리 생성은 끔.
3. [prompts/dreamina-video.txt](prompts/dreamina-video.txt)의 `[영상 생성]` 프롬프트를 붙인다.
4. 결과에서 볼 것: 물건이 늘거나 사라지지 않는가, 손가락이 뭉개지지 않는가, 색이 이미지와 달라지지 않는가, 카메라가 너무 빠르지 않은가.
5. `assets/03_video/`에 저장한다. 같은 씬을 다른 모델로 만들었다면 버전을 올리고 어떤 모델인지 작업 기록에 적는다.

의도한 대로 안 나온 씬이 하나는 생긴다. 그것을 5장 수정 기록의 대상으로 삼고, 수정 전 프롬프트와 결과 파일을 지우지 않는다.

## 5단계. 내레이션과 배경음악 (약 30분)

1. 음성 도구에 2단계에서 확정한 내레이션 네 문장을 한 번에 넣어 만든다. 전체 길이가 9초를 넘으면 속도를 올리지 말고 문장 사이 쉼을 줄이거나 문장을 줄인다. 빠른 말은 톤앤매너와 어긋난다.
2. 음악 도구에 배경음악 프롬프트를 넣는다. 10초로 지정되지 않으면 긴 곡을 받아 편집에서 앞 9.5초만 쓴다.
3. `assets/04_audio/`에 저장한다.
4. 음성·음악 도구도 무료 한도와 상업적 이용을 Dreamina와 같은 방식으로 확인해 6장에 적는다.

## 6단계. 통합과 내보내기 (CapCut, 약 40분)

1. CapCut에서 16:9 프로젝트를 만들고 씬 1~4 영상을 2.0 / 2.5 / 2.0 / 3.0초로 잘라 순서대로 놓는다. 이음은 샷리스트대로 S1→S2 하드컷, S2→S3 매치컷, S3→S4 0.3초 디졸브.
2. 내레이션을 얹고 문장이 각 씬 시작에 오도록 위치를 맞춘다. 배경음악은 내레이션보다 작게 낮추고 9.5초에서 페이드아웃한다. Seedance가 만든 소리가 있으면 음소거한다.
3. 자막을 3-1장 "씬 4 자막 배치"대로 넣는다(행동 유도 문구만 7.5초에 등장). 씬 2에 "어떻게 쉬고 싶나요", 씬 4에 "머물지도", "어디로 갈지보다, 어디에 머물지", "쉬는 방식부터 골라 보세요" (2단계에서 바꿨다면 바꾼 문구).
4. 씬 2~4의 밝기와 채도가 한 영상처럼 보이게 색보정한다.
5. 1280x720(또는 1080p), 30fps MP4로 내보낸다. **전체 길이가 10초를 넘지 않는지** 내보낸 파일에서 확인한다.
6. 파일을 `final/광고_머물지도.mp4`로 저장한다. 길이·해상도·프레임레이트는 아래 명령으로 확인해 스토리보드 8장에 적는다.

```bash
mdls -name kMDItemDurationSeconds -name kMDItemPixelWidth -name kMDItemPixelHeight final/광고_머물지도.mp4
```

CapCut의 AI 기능(자동 영상 생성, TTS, 배경 생성 등)은 쓰지 않는다.

## 7단계. 문서 마무리와 PDF 변환

1. [작업기록.md](작업기록.md) 내용을 스토리보드 9장으로 옮긴다.
2. `✏️`가 남아 있지 않은지 확인한다.
3. PDF로 만든다. 아래 명령은 `✏️`가 남아 있으면 개수를 알려 준다.

```bash
python3 make_pdf.py
```

4. [README.md](README.md)의 체크리스트를 처음부터 끝까지 확인한다.
5. 저장소에 올릴 때 MP4 용량을 확인한다. 웹 업로드는 25MB, Git 명령은 100MB까지다.

## 보너스 (선택)

지금 구성에서 품이 적게 드는 순서다.

| 번호 | 내용 | 이 광고에서 하는 방법 |
| --- | --- | --- |
| 3 | 화면 비율 버전 둘 이상 | 같은 CapCut 프로젝트를 9:16으로 복제한다. 씬 2는 물건 네 개가 가로로 놓여 양끝(수건, 성냥갑이나 손)이 잘리고, 씬 3은 창의 좌우가 잘린다. 무엇이 잘렸는지 적는다 |
| 2 | 도구만 바꿔 다시 만들기 | 씬 3 이미지 프롬프트를 그대로 다른 이미지 도구(Gemini 앱, ChatGPT 이미지 생성 등)에 넣어 빛, 색, 구도 차이를 적는다. 같은 Dreamina 안에서 모델만 바꾼 것(Seedance Mini와 2.0)은 "다른 도구"로 보기 애매하므로 따로 적는다 |
| 4 | Apps Script로 API 호출 | Seedance는 Dreamina 웹이 아니라 BytePlus(ModelArk) 같은 개발자 플랫폼에서 API로 제공된다고 알려져 있다. 공식 문서에서 API 유무와 키 발급 조건(결제 수단 필요 여부)을 확인해 적는다. 작업 큐 방식이면 요청 기록과 받은 작업 ID 응답만 적어도 충족한다. 키는 문서에 적지 않는다 |
| 1 | 인물이 말하는 장면과 입모양 | Dreamina에 립싱크(아바타) 기능이 있지만 얼굴을 쓰지 않기로 한 톤앤매너와 맞지 않는다. 한다면 본편과 분리한 별도 버전으로 만든다 |
