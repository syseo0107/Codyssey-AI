## 1단계. 도구 A — Make로 구현하기

### 완성 모양

```
[Gmail: Watch Emails]
   → [Google Gemini AI: Generate a response]   (분류 + 요약, JSON 한 줄)
   → [JSON: Parse JSON]                         (category, summary 꺼내기)
   → [Google Sheets: Add a Row]                 (A~E 열 기록, 행 번호 받기)
   → [Router]
        ├ 경로 A  필터: category = 견적
        │    → [HTTP: Make a request]           (Discord 웹훅으로 알림)
        │    → [Google Sheets: Update a Row]    (F열 = 알림완료)
        └ 경로 B  (fallback route: 나머지 전부)
             → [Google Sheets: Update a Row]    (F열 = 보관)
```

### ⚠️ 시작 전에 알아 둘 것 두 가지

**1) 개인 @gmail.com 계정은 Make에 바로 연결되지 않는다** → ✅ **2026-11-25 실제로 해 보니 기본 연결("Sign in with Google")로 바로 연결됐다.** Gmail 앱이 Version 4 · Verified로 바뀌어 있었다. 아래 내용은 예전 문서 기준이라 참고만 한다.

Make 공식 도움말에 따르면 Gmail은 제한된 권한(restricted scope)이라, 개인 Gmail 계정은 **Google Cloud에서 OAuth 클라이언트를 직접 만들어** Client ID / Client Secret을 Make에 넣어야 연결된다.
- 따라 할 문서: [Make 도움말 — Connect to Google services using a custom OAuth client](https://help.make.com/connect-to-google-services-using-a-custom-oauth-client)
- 큰 순서: Google Cloud 프로젝트 만들기 → Gmail API 사용 설정 → OAuth 동의 화면(외부, 테스트 모드) → 승인된 도메인에 `make.com`, `integromat.com` 추가 → **테스트 사용자에 테스트 Gmail 주소 추가** → OAuth 클라이언트(웹 앱) 만들기, 리디렉션 URI는 도움말에 적힌 Make 주소 → Make의 Gmail 연결 화면 "Show advanced settings"에 ID/Secret 입력
- 테스트 모드로 두면 **일주일마다 다시 인증**해야 한다고 한다. 캡처는 연결한 주에 몰아서 받는다.
- 권한 요청 화면에서는 워크플로우에 필요한 범위만 허용한다 (미션 제약 사항).
- 📝 이 과정 자체가 비교 항목("외부 서비스 연결 난이도")의 근거가 된다. 걸린 시간과 막힌 곳을 작업 기록에 바로 적는다.

**2) 무료 1,000 크레딧은 "확인 횟수"로도 빠진다**

Gmail Watch Emails는 정해진 간격마다 메일함을 확인하는 방식이라, 새 메일이 없어도 확인할 때마다 크레딧이 나갈 수 있다. 15분 간격으로 한 달 내내 켜 두면 1,000을 넘는다.
- 만드는 동안에는 **Run once**(수동 실행)로 확인한다.
- 자동 실행 캡처가 필요할 때만 스케줄을 켜고(15분 간격), 캡처를 받으면 **바로 끈다**.
- 메일 한 통 처리에 대략 5~6 크레딧이 든다 (트리거 1, Gemini 1, JSON 1, 시트 추가 1, 경로별 1~2. Router는 크레딧을 쓰지 않는다고 공식 페이지에 나옴). 실제 값은 실행 기록에서 확인해 비교표에 적는다.

### 만드는 순서

1. **시나리오 만들기**
   - Make → Scenarios → Create a new scenario. 이름: `메일분류-견적알림`

2. **트리거: Gmail → Watch Emails**
   - 연결: 위 1)의 커스텀 OAuth 클라이언트로 테스트 Gmail 연결
   - Folder: `INBOX`, Criteria: 읽지 않은 메일(unread) 또는 전체, Maximum number of results: `1`~`3`
   - 처음 실행할 때 "어디서부터 볼지"를 물으면 *From now on* 을 고른다 (기존 메일이 몰려 들어오지 않게)

3. **AI: Google Gemini AI → Generate a response**
   - 연결: AI Studio에서 받은 Gemini API 키
   - 모델: 무료 키로 쓸 수 있는 Flash 계열
   - 프롬프트: [설계문서.md](설계문서.md) "생성형 AI 액션에 넣은 프롬프트"의 v1을 붙여 넣고, `{{제목}}`·`{{본문}}` 자리에 Gmail 모듈의 Subject, Text content(본문)를 매핑
   - ⚠️ 응답이 ```` ```json ```` 코드블록으로 감싸여 오면 다음 단계에서 JSON 파싱이 실패한다. 그러면 프롬프트를 고치거나 옵션을 바꿔 보고, **그 과정을 `[수정]` 작업 기록으로 남긴다.** 끝까지 못 풀면 한계 기록 후보.

4. **JSON → Parse JSON**
   - JSON string: Gemini 모듈의 응답 텍스트
   - Data structure: Add → Generate → 샘플 `{"category":"견적","summary":"단체 워크숍 코스 견적 요청"}` 붙여 넣기

5. **Google Sheets → Add a Row**
   - 연결: 테스트 Google 계정 (Sheets는 기본 연결이 되는지 먼저 시도, 막히면 같은 OAuth 클라이언트 사용)
   - 스프레드시트 / 시트: 「메일분류」, Table contains headers: Yes
   - 받은시각 ← Gmail Date, 보낸사람 ← Sender email, 제목 ← Subject, 분류 ← `category`, 요약 ← `summary`, 처리상태는 비워 둠

6. **Router 추가** (Sheets 모듈 뒤 + 버튼 → Flow Control → Router)
   - **경로 A** 연결선의 렌치 아이콘 → Set up a filter
     - Label: `견적`
     - Condition: `category` / Text operators: **Equal to** / `견적`
   - **경로 B** 연결선 → Set up a filter → Label: `나머지`, **Fallback route: Yes** 체크

7. **경로 A: HTTP → Make a request**
   - URL: Discord 채널 웹훅 주소 (캡처할 때는 반드시 가린다)
   - Method: `POST`, Body type: Raw, Content type: `JSON (application/json)`
   - Request content 예:
     ```json
     {"content": "📩 견적 요청 도착\n제목: {{Subject}}\n요약: {{summary}}\n받은 시각: {{Date}}"}
     ```
     (`{{...}}`는 Make 매핑 패널에서 해당 값을 끌어다 넣는다)

8. **경로 A 마무리: Google Sheets → Update a Row**
   - Row number ← 5번 Add a Row 모듈이 돌려준 **Row number**
   - 처리상태: `알림완료`

9. **경로 B: Google Sheets → Update a Row**
   - Row number ← 같은 Row number, 처리상태: `보관`

10. **저장 후 테스트 (Run once)**
    - 테스트 메일 1통(문의)을 다른 계정에서 테스트 Gmail로 보냄 → Run once → 경로 B로 가는지 확인
    - 테스트 메일 2(견적) → Run once → Discord 알림 + 시트 "알림완료" 확인
    - 각 모듈 위 말풍선(숫자)을 눌러 들어온 값/나간 값을 확인 → **AI 결과가 다음 단계로 넘어간 캡처**는 여기서 받는다

11. **자동 실행 확인**
    - 왼쪽 아래 스케줄 토글 ON, 간격 15분
    - 메일 3·4를 보낸 뒤 손대지 않고 기다림 → History 탭에 자동 실행 기록이 쌓이면 캡처
    - 캡처 후 **스케줄 OFF**

### 만들면서 메모할 것 (비교 항목 재료)

- 화면 구성: 모듈을 원으로 잇는 방식, Router에서 갈라지는 모양
- 분기 설정: Router + 연결선마다 필터, fallback route
- 생성형 AI 블록: Gemini 모듈 이름, API 키 필요 여부, JSON을 따로 파싱해야 했는지
- 외부 서비스 연결: 개인 Gmail에 커스텀 OAuth가 필요했던 점, 걸린 시간
- 실행 기록: 모듈마다 들어온 값/나간 값이 보이는지
- 무료 사용량: 메일 한 통에 실제로 든 크레딧 수
- 막혔거나 포기한 기능 → 한계기록서 후보로 바로 적어 두기
