# 테스트 메일 (가상 데이터)

> 실제 업무 데이터나 개인정보가 아닌, 미션용으로 지어낸 메일이다.
> 회사·사람 이름은 모두 가상이며 보낸 사람 주소는 `example.com` 형식으로 둔다.
> 다른 계정(개인 메일 등)에서 테스트 메일함으로 보낼 때는 **제목과 본문만** 복사해 보낸다.
>
> 가상 회사: **머물지도** (여행지 추천 서비스, 2-1 미션에서 만든 서비스) — 대표 메일함으로 들어오는 메일이라고 가정한다.

| # | 기대 분류 | 분기 경로 | 용도 |
|---|---|---|---|
| 1 | 문의 | B (나머지) | 기본 동작 확인 |
| 2 | 견적 | A (견적 알림) | 경로 A 확인 |
| 3 | 광고 | B (나머지) | 기본 동작 확인 |
| 4 | 견적 | A (견적 알림) | 경로 A 재확인 |
| 5 | 문의 | B (나머지) | 견적처럼 보이지만 문의인 애매한 메일 — AI 분류 정확도 확인 |
| 6 | 광고 | B (나머지) | "견적" 단어가 들어간 광고 — 보너스 1(프롬프트 수정 전후 비교)용 |

---

## 메일 1 — 문의

- **제목:** [MMJTEST] 앱에서 저장한 여행지가 사라졌어요
- **본문:**

```
안녕하세요. 머물지도 앱을 잘 쓰고 있는 사용자입니다.
어제 '가고 싶은 곳' 목록에 제주 카페 세 곳을 저장해 두었는데,
오늘 다시 열어 보니 목록이 비어 있습니다.
로그아웃했다가 다시 들어가도 마찬가지입니다.
저장한 장소를 되살릴 방법이 있을까요?
```

## 메일 2 — 견적

- **제목:** [MMJTEST] 사내 워크숍용 단체 여행 코스 견적 요청
- **본문:**

```
안녕하세요, 가나다상사 총무팀입니다.
다음 달 둘째 주에 직원 25명이 1박 2일로 강릉 워크숍을 가려고 합니다.
머물지도에서 단체용 맞춤 코스(숙소·식당·체험 포함)를 짜 주실 수 있는지,
가능하다면 대략적인 비용 견적을 받고 싶습니다.
이번 주 금요일까지 회신 주시면 내부 보고에 반영하겠습니다.
```

## 메일 3 — 광고

- **제목:** [MMJTEST] [특가] 여행 앱 마케팅, 이번 달만 50% 할인!
- **본문:**

```
여행 서비스 운영자님, 앱 다운로드 수가 고민이신가요?
저희 라온애드는 SNS 광고 집행부터 리뷰 관리까지 한 번에 해 드립니다.
이번 달 신규 계약 시 첫 달 대행료 50% 할인!
지금 바로 상담 신청하세요.
수신을 원하지 않으시면 이 메일에 '거부'라고 회신해 주세요.
```

## 메일 4 — 견적

- **제목:** [MMJTEST] 숙소 제휴 입점 비용 문의드립니다
- **본문:**

```
안녕하세요. 전주 한옥마을에서 게스트하우스를 운영하고 있습니다.
머물지도 추천 목록에 저희 숙소를 제휴 숙소로 올리고 싶은데,
입점 비용과 수수료 구조를 견적서로 받아 볼 수 있을까요?
객실은 6개이고, 연중 운영합니다.
```

## 메일 5 — 문의 (애매한 메일)

- **제목:** [MMJTEST] 요금제가 따로 있나요?
- **본문:**

```
안녕하세요. 개인적으로 여행 계획을 세울 때 머물지도를 쓰려고 합니다.
무료로 쓸 수 있는 기능과 유료 기능이 나뉘어 있는지 궁금합니다.
유료라면 한 달에 얼마인지도 알려 주시면 감사하겠습니다.
```

> 메모: 가격을 묻지만 개인 사용자의 일반 문의다. AI가 "견적"으로 분류하면 프롬프트에 기준을 보태야 한다는 신호 → 작업 기록의 `[수정]` 후보.

## 메일 6 — 광고 ("견적" 단어 포함)

- **제목:** [MMJTEST] 무료 견적! 홈페이지 리뉴얼 패키지 안내
- **본문:**

```
여행·숙박 업종 홈페이지 전문 제작사 바람웹입니다.
지금 신청하시면 리뉴얼 견적을 무료로 받아 보실 수 있습니다.
반응형 디자인, 예약 연동, 유지보수까지 패키지로 제공합니다.
견적 신청은 아래 링크에서 1분이면 끝납니다.
```

> 메모: 제목에 "견적"이 들어가지만 상대가 보낸 광고다. 보너스 1에서 "우리에게 견적을 **요청**하는 메일만 견적" 같은 기준을 프롬프트에 넣기 전과 후를 비교하기 좋다.
